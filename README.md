# 黄阳投资课 · 阅读器

把 B 站 UP 主**「黄阳的学习分享」**的 **166 期股票投资视频**中文字幕，整理成一本可在线阅读的电子书。

**在线地址**：https://animerqi.github.io/huangyang-invest-reader/

## 这是什么

一个单文件电子书阅读器，共 **169 节**（阅读梗概 + 学习路径 + 166 期正文 + 附录），同一时间只显示一节，读完点「下一节」继续。

每一期的内容：

| 部分 | 说明 |
|---|---|
| 一句话核心观点 | 该期最核心的判断 |
| 内容梗概 | 220–400 字，讲清他为什么讲这个题、论证链条、结论 |
| 关键要点 | 5–8 条可直接照着做的干货 |
| 他的一句话 | 最能代表他思路的原话 |
| **正文 · 润色版** | 补全标点、重新分段、加了小标题的完整字幕稿，可当文章读 |
| 机器原稿 | 未经处理的原始转录，折叠保留供核对 |

## 为什么字幕需要「润色」

视频平台自动生成的字幕是**完全没有标点**的口语流，还带有大量语气词和同音错字，直接读非常困难。本项目的润色遵守一条原则——**只润色、不改写**：

- 不总结、不压缩、不扩写，信息量与原文完全一致
- 补齐全角标点，按语义重新分段（一段 1～4 句）
- 长视频加 `## 一、小标题 [MM:SS]` 分节，全合集共 1761 个小节
- 删除句末语气词（哈／啊／呢／吧）与无意义重复，保留有语义的口语表达
- 按上下文订正机器转录的瑕疵：`低速时尚` → 地素时尚、`周大神` → 周大生、`430` → 4月30日、`20177年` → 2017年、`5000178点` → 5178点

**校验结果**：166 篇全部生成，段落级重复 0 处，长度对原稿比值均落在 0.85～1.30（合计 1.09，多出的是标点），数字保真率 96.7%（未保留部分经逐条核对，绝大多数属于上述「粘连数字」修正）。

## 学习路径

他本人有一份 24 章的课程大纲（基础认知 / 公司经营 / 二级市场 / 高级篇）。本项目按那个骨架，把 166 期重排成 **15 个模块、10 步**：

导论 → 投资品种与市场常识 → 公司与行业 → 业务·商业模式·战略 → 财务与三表 → 估值 → 二级市场 → 组合与纪律 → 打新与可转债 → 行业分析 → 公司案例 → 宏观与周期 → 风控与心理 → 全市场财报汇总 → 市况随笔

顺序本身就是内容——这套方法论是层层咬合的，跳步看会少掉很多「为什么」。

## 阅读器功能

- **翻页**：底部「上一节 / 下一节」，或键盘 `←` `→`
- **全文检索**：同时搜标题、摘要、润色正文与机器原稿；`/` 聚焦、`Esc` 清空
- **目录**：15 个模块分组，当前节高亮；窄屏变抽屉
- **阅读设置**：字号六档、正文宋体／黑体切换
- **深链**：地址栏同步为 `#p<节号>`，可直接分享某一节

## 视觉风格

界面按一份《青花瓷》UI 规范实现：白瓷底色、钴蓝晕染、缠枝纹边框、釉面柔光、**瓶身弧形圆角**（上窄下宽，全站统一）；细宋体正文、标题宽字距、数字 `tabular-nums`、每页右侧竖排题签。浅色单基调，不提供深色反转。

无障碍：正文/次要/强调色对白底对比度 11.26 / 5.63 / 6.85 : 1，均 ≥4.5:1；全部可交互元素短边 ≥44px；`:focus-visible` 可见焦点；页面主体在电脑／平板／手机三档视口下均无横向滚动。

## 技术实现

纯静态单文件 HTML，无构建、无依赖、无外部请求，离线可用（约 5.3 MB）。
